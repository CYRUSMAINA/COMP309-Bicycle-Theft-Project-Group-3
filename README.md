COMP309 Bicycle Theft Prediction Project
Overview
A data analysis and machine learning project developed as part of the COMP309 Data Warehouse & Predictive Analytics course at Centennial College.
The project uses a bicycle theft dataset to analyze patterns associated with stolen bicycles and develop a machine learning model to predict whether a reported stolen bicycle is likely to be recovered.
This was assigned as a group project. I completed approximately 80% of the project work, including the data analysis, preprocessing, machine learning development, API implementation and  dashboard development.
Project Components
1. Data Analysis & Preprocessing
•	Loaded and explored the bicycle theft dataset using Python.
•	Cleaned and prepared the data for machine learning.
•	Handled missing numerical and categorical values.
•	Encoded categorical variables.
•	Applied feature scaling and feature selection.
•	Used SMOTE to address class imbalance.
2. Machine Learning
Developed classification models using scikit-learn, including:
•	Logistic Regression
•	Decision Tree
Model performance was evaluated using classification metrics and visualizations.
The project includes the trained preprocessing components and machine learning model used by the prediction API.
3. Flask API
Developed a Flask-based API to provide access to the trained prediction model.
The API was deployed using Render.
Live API: https://bicycle-theft-api.onrender.com
4. React Dashboard
Developed a React-based dashboard to provide an interactive interface for exploring bicycle theft information and interacting with the prediction functionality.
The dashboard was deployed using Netlify.
Live Dashboard: https://bicycle-theft-prediction.netlify.app/
5. Data Visualization
The project includes data visualization and exploration using:
•	Power BI
•	Tableau
•	Python visualization tools
